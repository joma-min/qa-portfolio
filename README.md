# qa-portfolio
My QA Engineer Portfolio
Привет! Я начинающий QA инженер. Здесь собраны мои практические работы по ручному и автоматизированному тестированию.

## 🛠 Стек технологий
* **Тестирование:** Ручное тестирование (тест-кейсы, чек-листы, баг-репорты), API-тестирование.
* **Инструменты:** Postman, DBeaver, Git.
* **Автоматизация:** Playwright (JavaScript).
* **Базы данных:** SQL (написание запросов).

## 📂 Структура репозитория
* `01_Manual_Testing/` — тест-кейсы, чек-листы и баг-репорты.
* `02_API_Testing/` — коллекции Postman.
* `03_SQL_Databases/` — примеры SQL-запросов.
* `04_Automation_Playwright/` — автотесты.
